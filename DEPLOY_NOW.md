## 🌐 **MANUAL DEPLOYMENT**

If you prefer manual setup:

```bash
# Clone the repo
git clone -b claude/neurafield-quantum-platform-bf4VV https://github.com/aziriel2020/Aziriel.git
cd Aziriel

# Install dependencies
npm install

# Set up database
npx prisma generate
npx prisma db push

# Start the server
npm run dev
```

Then expose online with:
```bash
# Install ngrok
npm install -g ngrok

# Expose your app
ngrok http 4000
```
